# Mecare Hospital Website

A modern, responsive hospital website built with HTML, CSS, and JavaScript. This project features a preloader, animated hero slider, doctor and services sections, appointment booking, contact section with embedded Google Map, animated counters, and smooth navigation.

## Features
- Preloader with animated logo
- Hero section with sliding images and animated counters
- Doctors section with animated cards
- Services section with icons and hover effects
- Appointment booking form
- Contact section with Google Map
- Scroll up/down arrows for easy navigation
- Responsive design for all devices
- Smooth animations and modern UI
